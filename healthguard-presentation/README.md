# HealthGuard AI — Presentation

Interactive React pitch deck for **HealthGuard AI**: problem, architecture, AI/ML pipeline, clinical workflow, impact, and roadmap.

## Run locally

```bash
cd healthguard-presentation
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Stack

- React 18 + Vite  
- Framer Motion  
- Lucide icons  

## Slides cover

1. Title & team  
2. Problem statement  
3. Solution overview  
4. Why sleep apnea  
5. Multi-layer architecture  
6. AI/ML pipeline (ECG → Random Forest)  
7. Explainable AI + generative patient communication  
8. Multi-portal design  
9. Clinical terminology (SNOMED / Zudoc)  
10. End-to-end clinical use case  
11. Impact & future roadmap
